Postdesk

A dashboard for publishing our own video content to TikTok, Instagram and YouTube from one place.

This is an internal tool. It is used only by our own team to publish content to social media accounts we own. It is not offered to, or usable by, third parties.

What it does

  • Select a video from the computer and preview it before anything is sent
  • Write one caption that is adapted per account and per brand
  • Choose which connected accounts to publish to
  • Set the platform options for each post, with nothing preselected
  • Review exactly what will be published, and confirm before it is sent

How we use the TikTok API

  • Login Kit authenticates the owner of the account and shows the creator nickname in the dashboard, so the correct account is confirmed before posting.
  • Content Posting API uploads the selected video using Direct Post. The creator's current settings are fetched and displayed first. The user actively selects a privacy level, can disable comments, duet and stitch, and declares commercial content where it applies.

How we use the YouTube and Instagram APIs

  • YouTube Data API uploads the video to our own channel, with the visibility and made-for-kids declaration set by the user.
  • Instagram Graph API publishes the video as a Reel to our own professional account.

Data

We store only the access tokens needed to publish on behalf of accounts we own. We do not collect data about viewers, followers or any other person. See the privacy policy for details.
